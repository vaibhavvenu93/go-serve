# Customer Home image provenance

Created with the built-in ImageGen tool. These are generated food photographs for the fictional prototype, not photographs of an actual GO SERVE kitchen. No remote image requests are made by the application.

Final assets are in `public/food/`. The paneer hero is a 900px WebP; supporting dishes are 600px WebP. Total source asset payload is approximately 411 KiB before Next/Image responsive optimization. Original generated PNGs remain untouched in the generator output directory. Only size/format compression was performed locally; no image content was edited. Next/Image reserves dimensions, prioritizes the hero, and lazy-loads supporting imagery. A textual fallback preserves layout on failure.
